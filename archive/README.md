# Archive

Retired, superseded, or reorganized material lives here. Paths mirror the source tree relative to `src/`: `src/concepts/example.md` becomes `archive/concepts/example.md`; `src/strategy/example.md` becomes `archive/strategy/example.md`.

Record the archive date, reason, and replacement link in each retired document. Archived does not automatically mean rejected. Active documents link to their current source; archive copies are historical context.

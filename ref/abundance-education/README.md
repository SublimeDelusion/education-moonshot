## How to use these sources

Cite the Markdown filename and `PDF page N` when extracting evidence. Preserve the distinction between statements made in these materials and independently verified facts. Keep interpretation and synthesis in separate documents so the source layer remains traceable.

## Conversion and quality notes

- All five PDFs are image-based browser print captures. OCR was run across all 52 pages; every page has a corresponding Markdown section.
- Page thumbnails were visually reviewed to identify chart-heavy content and missing source sections. This is a first-pass OCR transcription, not a line-by-line certified transcription.
- `ae-whatfailed.pdf` has blank body pages 3, 4, and 6; most of the advertised detailed analysis is absent from the PDF itself. A fresh capture of the original webpage is needed to recover it. No replacement text was invented.
- Charts and some multi-column cards/tables flatten imperfectly into OCR reading order. Refer to the PDF before quoting chart values or relying on row/column associations. Chart-heavy pages carry local notes.
- The original filename `abuundance-education.pdf` is retained, including its spelling, to preserve the mapping.
- URLs identify the original webpages printed in the PDFs. The live webpages were not substituted for the supplied source snapshots.

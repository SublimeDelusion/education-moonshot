# Education Moonshot

**To make education more human.**

A model for purpose-driven, AI-accelerated post-secondary education centered on the student and the human connections they need to succeed.

University of Impact is the working name used in the story and current model. The eventual institutional form and name remain open.

[docs/](docs/README.md) contains the GitHub Pages website, published from **main /docs**. Canonical copy remains in `src/`; `tools/build-site.mjs` generates the four pages. The parent Q&A is a first draft; the operating model carries its review status.

Keep one authoritative home per document in `src/`. Edit the source first, then regenerate its distribution edition in `assets/`. Record a concept's status and reasoning with the concept. Archive retired source material by its path relative to `src/` (for example, `src/concepts/example.md` becomes `archive/concepts/example.md`). Mark exploratory proposals clearly.

This repository owns the education model and canonical manuscript of *Anya's Ascent*.
